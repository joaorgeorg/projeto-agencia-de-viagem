🌍 TOURIST - AGÊNCIA DE VIAGENS | DEPLOYMENT-READY TEMPLATE
================================================================================

Bem-vindo ao projeto Tourist! Este não é apenas mais um template; é uma 
plataforma web de alta performance, projetada com os rigorosos padrões 
de um desenvolvimento frontend sênior.

Cada linha de código foi revisada, otimizada e estruturada para oferecer 
a melhor experiência possível tanto para os usuários quanto para os motores 
de busca (SEO).

🚀 DESTAQUES DO PROJETO
--------------------------------------------------------------------------------
• 100% Responsivo: Layout perfeitamente adaptável para Mobile, Tablet e Desktop, sem quebras de layout.
• SEO Premium: Meta tags, descrições e palavras-chave estrategicamente inseridas e prontas para indexação.
• UX/UI Impecável: Micro-animações suaves, espaçamentos consistentes e tipografia legível.
• Interações Funcionais: 
  - Galeria do rodapé com Modal dinâmico (Visualização imersiva da foto em clique).
  - Formulários "Safe-Click" (Prevenção de reload indesejado com alertas integrados).
  - Prevenção de âncoras fantasmas (Links vazios bloqueados para manter a estabilidade da navegação).
• Acessibilidade e Encoding: 100% de compatibilidade com caracteres e acentuações do PT-BR (UTF-8 nativo restaurado e consolidado).
• Localização Monetária: Todos os preços convertidos e formatados para a moeda Real (R$).

💻 TECNOLOGIAS UTILIZADAS
--------------------------------------------------------------------------------
- HTML5 Semântico
- CSS3 (Variáveis nativas e Media Queries customizadas)
- Bootstrap 5 (Framework base de grid e utilitários)
- JavaScript / jQuery (Para interatividade do Modal, Carrossel e validações)

🛠️ COMO EXECUTAR (ZERO CONFIGURAÇÃO)
--------------------------------------------------------------------------------
1. Este é um projeto puramente estático (Client-Side). 
2. Nenhuma instalação pesada, build ou servidor Node.js é necessário.
3. Basta abrir o arquivo `index.html` no seu navegador preferido ou 
   jogar os arquivos diretamente em plataformas de hospedagem como Vercel, Netlify ou GitHub Pages para um deploy em segundos.

📈 PREPARADO PARA ESCALAR
--------------------------------------------------------------------------------
O código foi refatorado pensando no futuro. Se amanhã houver a necessidade de 
transformar este projeto em uma aplicação React, Vue, ou integrar com um 
backend (PHP, Node, Python), a estrutura modular e a separação clara 
das responsabilidades garantirão que o time de engenharia faça isso com facilidade.
